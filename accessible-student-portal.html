This portal has been specially created for blind, low-vision, and keyboard-only students. It provides high-clarity speech narration, debounced focus speaking, two-step application confirmations, and voice command controls.

💡 How Accessible Mode Works (Technical Architecture)

Comprehensive breakdown of GovSkill Connect's assistive architecture, zero duplicate database strategy, and WCAG AAA compliance for evaluators.

1. Zero Duplicate Database Architecture

The Accessible Student Portal operates upon the exact same data store and relational schemas as the standard GovSkill Connect portal. When a student updates their profile, adds an education record, or submits a government job application in Accessible Mode, the changes are written directly to API and LocalStore. Returning to the standard portal displays identical, synchronized state instantly without any data duplication.

2. Web Speech API SpeechSynthesis Engine

Built on the native browser window.speechSynthesis interface, requiring zero external server dependencies, Python runtimes, or paid third-party cloud APIs. The engine features speech priority interruption queues, voice rate adjustments, and polite fallback mechanisms.

3. Debounced Focus Speaking Engine (220ms)

Rapid keyboard navigation can often cause overwhelming auditory noise on unoptimized web portals. GovSkill Connect introduces a 220ms debounce window on all focusin events. When a user tabs rapidly through elements, only the actively settled element speaks, announcing its semantic role, current value, and keyboard instructions.

4. Voice Command Assistant & Two-Step Confirmations

Using webkitSpeechRecognition, users can speak natural commands such as "open dashboard", "open profile", "show opportunities", "show applications", or "read this page". Critical actions like submitting a job application enforce a mandatory two-step spoken confirmation modal, preventing accidental submissions.

5. WCAG 2.1 Level AAA & GIGW Compliance

  • High Contrast Themes: 7:1+ contrast ratio across all text and borders, surpassing AAA thresholds.
  • Focus Indicators: 4px high-visibility focus ring (#ffb703) with 3px offset and zero keyboard traps.
  • Target Sizing: All interactive touch and click targets satisfy the minimum 48px standard.
  • Global Access Shortcut: Alt + A triggers accessible mode instantly across the platform.
